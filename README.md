# 🐍 Dynamic Causal Modeling (DCM) for fMRI in Python

This repository provides a Python implementation of **Parametric Dynamic Causal Modeling (P-DCM)** for fMRI.
It is intended for researchers who already use **SPM (MATLAB)** for fMRI preprocessing and DCM model setup, and who want to run model inversion and visualization in Python.

This repository **does not contain any fMRI data**.
Users must provide their own SPM-exported `.mat` files containing time-series, connectivity matrices, and stimulus inputs.

---

## 🌟 Overview

This code allows users to:

* Load regional fMRI time-series and stimulus inputs exported from SPM
* Define intrinsic, modulatory, and driving connectivity (A/B/C/D)
* Run variational Bayesian inversion via a Python implementation of SPM-style `spm_nlsi_GN`
* Save subject-level results as `.pkl` files
* Visualize:

  * Effective connectivity matrices
  * Directed connectivity graphs
  * Predicted vs. observed BOLD time-series
  * Input functions

The codebase is modular, lightweight, and easy to adapt for custom DCM structures or datasets.

## ✅ Required Inputs (User-Supplied)

You must export these from **SPM’s DCM model** or prepare them as equivalent `.mat` files.

### 1. fMRI time-series

A `.mat` file containing regional BOLD signals, e.g.:

```
Y = [n_regions x T]    # or [T x n_regions]
```

### 2. Stimulus / Input Time-Series

A `.mat` file containing:

```
U = [T x n_inputs]     # from SPM: DCM.U.u
```

### 3. Connectivity Matrices

A `.mat` file containing:

```
A  # intrinsic connectivity
B  # modulatory effects (list or 3-D array)
C  # driving inputs
D  # nonlinear modulation (optional)
```

These typically mirror `DCM.a`, `DCM.b`, `DCM.c`, `DCM.d`.

### 4. (Optional) Region Labels

Improves readability in visualizations:

```
labels = {'IOG-L', 'IOG-R', ...}
```

## ▶️ Running P-DCM

1. Place your `.mat` files in a folder such as:

```
data/
  fmri.mat
  inputs.mat
  connectivity.mat
  labels.mat   (optional)
```

2. Edit paths in `code/utilities/run_pdcm.py`:

```python
path_fmri = "../data/fmri.mat"
path_U    = "../data/inputs.mat"
path_conn = "../data/connectivity.mat"
path_lab  = "../data/labels.mat"   # optional
```

3. Run the model:

```bash
cd code
python -m utilities.run_pdcm
```

The script will:

* Load your `.mat` data
* Build the DCM model
* Perform EM / VB updates
* Save a `.pkl` results file containing connectivity parameters and predicted BOLD

## 👀 Visualizing Connectivity & BOLD Fits

Use the visualization script:

1. Set the results file path in `analyze_connectivity.py`:

```python
result_path = "../results/subject01_pdcm.pkl"
```

2. Run:

```bash
python -m analyze_connectivity
```

You will see:

* Effective connectivity matrix
* Connectivity graph
* Stimulus input plot
* Predicted vs. observed BOLD for each region

Close each figure to move to the next.
